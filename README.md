# Web Technologies — Midterm Courses

Interactive study courses for the AIUB Web Technologies midterm. Four courses, all client-side static (no build step):

- **Theory** — client-server, HTTP, URI, DNS, status codes, methods
- **HTML** — structure, elements, forms, DOM, semantic tags
- **CSS** — selectors, box model, position, specificity
- **JavaScript** — types, gotchas, DOM manipulation, form validation (with runnable code)

## Features
- Sidebar topic navigation per course
- Step-by-step lessons in plain language with memory hooks
- Collapsible self-test MCQs with explanations (85 questions)
- Progress tracking saved in the browser (localStorage)
- Runnable code examples in the JavaScript course
- Mobile-friendly

## Run locally
Just open `index.html` in a browser — no server or build needed.

## Tech
Plain HTML/CSS/JavaScript. Content lives in `assets/data/*.js`; rendering in `assets/app.js`.
